# Weather sounds app

Простое приложение на **чистом JavaScript + TypeScript** для воспроизведения звуков природы.

## Что реализовано

- Регулятор громкости (`input[type=range]`).
- Кнопки для запуска звуков.
- Звуки не накладываются: при запуске нового предыдущий останавливается.
- Повторное нажатие на активную кнопку ставит звук на паузу, следующее нажатие продолжает воспроизведение.
- При выборе звука фон страницы переключается на соответствующую картинку.

## Структура

- `index.html` — разметка страницы.
- `styles.css` — стили интерфейса.
- `main.ts` — TypeScript-версия логики.
- `main.js` — JavaScript для запуска в браузере.

## Assets

Приложение ожидает файлы в папке `assets`:

- `summer.mp3`, `rain.mp3`, `winter.mp3`
- `summer-bg.jpg`, `rainy-bg.jpg`, `winter-bg.jpg`
- `icons/sun.svg`, `icons/cloud-rain.svg`, `icons/cloud-snow.svg`
